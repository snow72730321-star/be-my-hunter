# Be My Hunter · 서림 v0.2.0

[바로 플레이](https://snow72730321-star.github.io/be-my-hunter/)

GDevelop 기반 프롤로그·챕터 1 시제품입니다. Safari/Chrome에서 주소를 열어 플레이합니다.

## 이번 변경

- 캐릭터 생성 최종 능력치 확인과 저장 이어하기.
- 핵심 1·보조 3칸의 별도 패시브, 조사·의료 의뢰에 따른 학습.
- 지역 결과 이후 수리대·소유자 확인·생활 의료·태오 지원 의뢰 4개.
- 원래 붕괴 지역을 유지하면서 안전한 임시거점에 상점 재개.
- NPC 구조 예약 충돌 수정, 이능 사용 성장, 출처 있는 증거 기록.
- 0.1 저장 파일을 이전하며 돈·생존·부상·게임 시계·난수 유지.

## 저장

저장은 현재 브라우저에 보관됩니다. 처음 화면의 이어서 하기 또는 저장 메뉴를 사용합니다. 별도 파일 내보내기/가져오기도 제공합니다.

## 범위와 검증

자동 검사 36개와 공식 런타임 연결 검사를 통과했습니다. Chrome 공개 URL에서 생성 확인·기존 저장 이어하기·패시브·훈련·시나리오 파일 가져오기·후속 의뢰·임시거점 구매를 확인했습니다. 실제 iPhone/Safari 장시간 사용은 미검증입니다.

2장 이후·환상용궁·펫·계열 융합·전체 경제는 아직 플레이할 수 없습니다. 그림은 SVG 임시 에셋이며 정식 도트 모션이 아닙니다.

실행에는 외부 AI API와 별도 게임 서버가 필요하지 않습니다. GDevelop 라이선스는 GDJS-LICENSE.md에 있으며 라이브러리 저작권은 각 파일에 유지됩니다.
