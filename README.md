# Be My Hunter · 서림

GDevelop 기반의 모바일 브라우저용 프롤로그·챕터 1 시제품입니다.

## 플레이

GitHub Pages 주소를 Safari 또는 Chrome에서 엽니다. 앱 설치와 외부 파일 불러오기는 필요하지 않습니다.

저장은 현재 기기와 브라우저에 보관됩니다. 게임 내 저장 메뉴에서 수동 저장과 내보내기를 사용할 수 있습니다.

## 배포

이 폴더의 내용 전체를 저장소 루트에 올린 뒤 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다. 별도 빌드는 필요 없습니다.

## 범위

프롤로그, 캐릭터 생성, 챕터 1, 전투, 지역 선택, 저장/불러오기. 그래픽은 임시이며 이후 챕터는 포함하지 않습니다.

GDevelop 런타임 라이선스는 GDJS-LICENSE.md에 있습니다. 포함된 외부 라이브러리의 저작권 표시는 각 파일에 유지되어 있습니다.
